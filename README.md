# 📂 FileFlow

A simple File Management System built using Python.

## ✨ Features

- Create a file
- Read a file
- Rename a file
- Append data
- Overwrite data
- Delete a file

## 🛠 Technologies Used

- Python
- pathlib
- os

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/FileFlow.git
```

Go into the project folder:

```bash
cd FileFlow
```

Run:

```bash
python app.py
```
